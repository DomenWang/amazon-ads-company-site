# 深圳市旅运航商贸有限公司胶带产品官网

这是一个可直接部署到 GitHub Pages 的静态公司介绍页，包含：

- `index.html`：公司主页与 Amazon Ads API 使用说明
- `privacy.html`：隐私政策
- `styles.css`：响应式样式

首页已加入你提供的 Amazon 店铺入口，发布前请确认该店铺链接长期有效。

## 发布前必须修改

发布前确认公司全称与营业执照完全一致，并检查页面中的电话和邮箱是否仍为公司公开联系方式。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `amazon-ads-company-site`。
2. 将本目录中的文件上传到仓库根目录。
3. 进入仓库的 `Settings` → `Pages`。
4. 选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/ (root)`，保存。
5. 等待部署完成后，使用 GitHub Pages 生成的 `https://用户名.github.io/仓库名/` 地址访问。

建议后续购买并绑定公司自己的域名，再把公司域名填写到 Amazon Ads API 申请表中。GitHub Pages 不应存放任何 OAuth、Refresh Token、密码、Cookie 或广告数据。
